# SCIEED261 Research Profile Questionnaire

Graduate student research profile questionnaire for **SCIEED261 – Advanced Environmental Science**, facilitated by **Dr. Ryan Manuel D. Guido**. Responses are collected through [Formspree](https://formspree.io).

## Setup

1. Create a form at formspree.io and copy its form ID.
2. In `index.html`, replace `YOUR_FORM_ID` with your ID:
   `action="https://formspree.io/f/YOUR_FORM_ID"`
3. Upload `index.html`, `README.md`, and `.nojekyll` to a new GitHub repository.
4. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
5. The form will be live at `https://<username>.github.io/<repository>/` within a few minutes.

## Privacy

Personal data are processed in accordance with the Data Privacy Act of 2012 (RA 10173). See the notice in the form.
